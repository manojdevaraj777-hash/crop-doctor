# Crop Doctor sample images

These public PlantVillage examples are included for local diagnosis testing.

- `tomato-early-blight.jpg` - Tomato early blight
- `tomato-late-blight.jpg` - Tomato late blight
- `potato-late-blight.jpg` - Potato late blight
- `apple-apple-scab.jpg` - Apple scab
- `grape-black-rot.jpg` - Grape black rot

Open the image files from this folder and upload them in Crop diagnosis. These are examples for testing the Gemini integration, not a replacement for field inspection or agronomist confirmation.

Source: https://github.com/spMohanty/PlantVillage-Dataset
